## 🚀 Использование

### Для тестирования API
```bash
# Получить ленту уловов
GET /api/v1/feed?type=all&page=1&limit=20

# Получить конкретный улов
GET /api/v1/catch/{id}

# Получить треки
GET /api/v1/tracks
```

### Для тестирования фронтенда
- Откройте приложение в браузере
- Перейдите в раздел "Лента"
- Просмотрите карточки уловов с изображениями
- Проверьте отображение координат на карте
- Протестируйте детальные страницы уловов
