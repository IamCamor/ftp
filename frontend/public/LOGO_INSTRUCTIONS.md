# Инструкция по замене логотипа

## ⚠️ ВАЖНО: Замените PNG файл

**Текущий статус:** Конфигурация настроена на `/logo.png`, но файл пустой.

## Что нужно сделать:

### 1. Замените файл logo.png
Скопируйте вашу PNG картинку "FishTrackPro" в граффити стиле в файл:
```
/var/www/ftp/frontend/public/logo.png
```

### 2. Соберите проект
```bash
cd /var/www/ftp/frontend
npm run build
```

## Текущая конфигурация:
- **Логотип:** `/logo.png` (пустой файл - нужно заменить)
- **Favicon:** `/favicon.svg` (работает)
- **PWA иконки:** `/icon-*.svg` (работают)

## После замены файла:
Логотип будет доступен по адресу: `https://fishtrackpro.ru/logo.png`
