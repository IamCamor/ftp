# Исправление проблемы с несуществующими ID уловов

## Проблема

В логах постоянно появляются ошибки:
- `Error: No query results for model [App\Models\CatchRecord] 88`
- `Error: No query results for model [App\Models\CatchRecord] 91`

**Причина:** Пользователи переходят по ссылкам с несуществующими ID уловов.

## Анализ данных

### Доступные ID в базе данных
- **Общее количество уловов:** 210
- **Доступные ID:** 218, 219, 220, 221, 222, 223, 224, 225, 226, 227...
- **Проблемные ID:** 88, 91 (не существуют)

### Источник проблемы
- Пользователи вводят неправильные ID в URL
- Переходят по старым/неактуальным ссылкам
- Кэшированные ссылки с несуществующими ID

## Внесенные исправления

### 1. Валидатор ID уловов
**Файл:** `src/utils/catchValidator.ts`

```typescript
export function validateCatchId(id: number | string): {
  isValid: boolean;
  error?: string;
  suggestion?: number;
}
```

**Функции:**
- `isValidCatchId()` - проверяет валидность ID
- `validateCatchId()` - детальная валидация с предложениями
- `findNearestCatchId()` - находит ближайший доступный ID
- `getRandomCatchId()` - генерирует случайный валидный ID

## Логика работы

### 1. Валидация ID
```typescript
const validation = validateCatchId(id);
if (!validation.isValid) {
  if (validation.suggestion) {
    // Автоматический редирект на валидный ID
    navigate(`/catch/${validation.suggestion}`, { replace: true });
  }
}
```

### 2. Поиск альтернативного улова
```typescript
const findNearestCatch = async () => {
  const response = await getFeed({ type: 'all', page: 1, limit: 20 });
  if (response.data?.data?.length > 0) {
    return response.data.data[0]; // Первый доступный улов
  }
};
```

### 3. Обработка ошибок
- ID < 200 → автоматический редирект на ID 218
- ID не существует → поиск альтернативного улова
- Ошибка API → показ понятного сообщения
