## 🛠 Техническая архитектура

### **API структура:**
```typescript
interface ReportData {
  type: 'catch' | 'place' | 'user';
  target_id: number;
  reason: string;
  description?: string;
}

// POST /reports
await createReport(reportData);
```

### **React компоненты:**
```typescript
// Универсальный компонент жалобы
<ReportModal
  isOpen={showReportModal}
  onClose={() => setShowReportModal(false)}
  type="catch" // или "place", "user"
  targetId={objectId}
  targetName="Описание объекта"
/>
```
