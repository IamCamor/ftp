# Лента уловов (CatchFeed)

Современный компонент ленты уловов в стиле Instagram для рыболовного приложения.

## Основные возможности

### 📱 Структура поста
- **Аватарка рыбака** - круглая фотография пользователя
- **Имя рыбака** - отображается под аватаркой
- **Фото улова** - основной визуальный контент (400x400px)
- **Место ловли** - геопозиция с иконкой
- **Дата публикации** - форматированная дата
- **Вид рыбы** - название рыбы с иконкой
- **Вес улова** - крупным шрифтом в оранжевом бейдже
- **Лайки** - с анимацией при нажатии
- **Комментарии** - количество комментариев
- **Поделиться** - иконка для шаринга

### 🎯 Таб-фильтры
1. **"Все уловы"** - глобальная лента всех пользователей
2. **"Локально"** - уловы рядом с пользователем по геолокации
3. **"Друзья"** - уловы друзей и подписок

### 🔄 Бесконечный скролл
- Автоматическая подгрузка контента при прокрутке
- Intersection Observer для оптимизации производительности
- Индикатор загрузки с анимацией

### 📦 Дополнительные блоки
Вставляются каждые 20 постов:

1. **После первых 20 постов**: Слайдер групп
   - Горизонтальный скролл
   - Название группы и фото
   - Количество участников

2. **После следующих 20**: Блок мероприятий
   - Ближайшие события в стране пользователя
   - Дата, место, фото мероприятия

3. **После следующих 20**: Приглашение друзей
   - CTA с градиентным фоном
   - Призыв к действию для приглашения друзей

4. **После следующих 20**: Блок погоды
   - Погода в выбранных точках
   - Температура и условия
   - Иконки погоды

### 🎨 Дизайн и анимации

#### Цветовая палитра
- **Основные**: синие и голубые тона (#3b82f6, #1d4ed8)
- **Акценты**: оранжевый (#f97316) для веса улова
- **Дополнительные**: зеленый для мероприятий, голубой для погоды

#### Микроанимации
- **Появление постов**: fadeInUp анимация
- **Лайки**: heartBeat анимация при нажатии
- **Hover эффекты**: поднятие карточек, изменение теней
- **Переходы табов**: slideIn анимация
- **Загрузка**: pulse анимация для индикатора
- **Иконки**: bounce эффект при наведении

#### Градиенты
- **Приглашения друзей**: анимированный градиент
- **Кнопки**: градиентные фоны с hover эффектами
- **Вес улова**: оранжевый градиент с тенью

## Использование

```tsx
import CatchFeed from './components/CatchFeed';

function App() {
  return (
    <div className="min-h-screen bg-gray-50">
      <CatchFeed />
    </div>

```

## Технические детали

### Зависимости
- React 18+ с хуками
- TypeScript для типизации
- Lucide React для иконок
- Tailwind CSS для стилизации

### Производительность
- Виртуализация через Intersection Observer
- Ленивая загрузка изображений
- Оптимизированные анимации CSS
- Мемоизация компонентов

### Адаптивность
- Мобильный дизайн (max-width: 640px)
- Поддержка темной темы (prefers-color-scheme)
- Кастомный скроллбар
- Touch-friendly интерфейс

## Моковые данные

Компонент включает в себя полный набор моковых данных:
- 50 постов уловов с различными типами рыб
- 4 группы с аватарами и количеством участников
- 2 мероприятия с датами и локациями
- 2 точки погоды с температурой и условиями

## Кастомизация

### Изменение цветов
Отредактируйте CSS переменные в `CatchFeed.css`:

```css
:root {
  --primary-blue: #3b82f6;
  --accent-orange: #f97316;
  --success-green: #10b981;
}
```

### Настройка анимаций
Измените параметры анимаций в CSS:

```css
.catch-post {
  animation: fadeInUp 0.5s ease-out; /* Изменить время */
}
```

### Добавление новых блоков
Расширьте функцию `insertSpecialBlock` в компоненте для добавления новых типов контента.
