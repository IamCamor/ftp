# Отчет об исправлении дублирующихся карточек на карте

## ✅ Проблема решена

### 🐛 **Проблема**
При нажатии на точку/улов на карте показывались **2 одинаковые карточки**:
1. **Popup карточка** - встроенная в Leaflet маркер
2. **Overlay карточка** - отдельная карточка поверх карты

### 🔧 **Причина дублирования**
В компоненте `MapScreen.tsx` была следующая логика:
```tsx
<Marker
  eventHandlers={{
    click: () => setSelectedPoint(point), // Устанавливает selectedPoint
  }}
>
  <Popup>
    <PointPinCard point={point} /> // Показывает карточку в попапе
  </Popup>
</Marker>

{/* И еще одна карточка в overlay */}
{selectedPoint && (
  <div className="selected-point-overlay">
    <PointPinCard point={selectedPoint} />
  </div>
)}
```

### ✅ **Решение**
Убрали дублирование, оставив только **overlay карточку**:

#### **Изменения в MapScreen.tsx**:
1. **Убрали Popup** из маркеров
2. **Убрали импорт Popup** из react-leaflet
3. **Оставили только overlay карточку** при клике

#### **До исправления**:
```tsx
import { MapContainer, TileLayer, Marker, Popup } from 'react-leaflet';

<Marker
  eventHandlers={{
    click: () => setSelectedPoint(point),
  }}
>
  <Popup>
    <PointPinCard point={point} onClose={() => setSelectedPoint(null)} />
  </Popup>
</Marker>
```

#### **После исправления**:
```tsx
import { MapContainer, TileLayer, Marker } from 'react-leaflet';

<Marker
  eventHandlers={{
    click: () => setSelectedPoint(point),
  }}
/>
```
