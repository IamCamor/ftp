# Swagger API Documentation Setup

## Обзор

Swagger (OpenAPI) документация успешно настроена для проекта FishTrackPro. Это позволяет разработчикам сторонних приложений легко тестировать и интегрироваться с API.

## Доступ к документации

### Swagger UI (Интерактивная документация)
- **URL**: `http://localhost:8000/api/documentation`
- **Описание**: Веб-интерфейс для тестирования API эндпоинтов
- **Возможности**: 
  - Интерактивное тестирование API
  - Автоматическая генерация примеров запросов
  - Встроенная аутентификация

### JSON документация
- **URL**: `http://localhost:8000/docs`
- **Описание**: OpenAPI спецификация в JSON формате
- **Использование**: Для генерации клиентских SDK и автоматизации

## Документированные эндпоинты

### Аутентификация
- `POST /auth/register` - Регистрация нового пользователя
- `POST /auth/login` - Вход в систему

### Лента уловов
- `GET /feed` - Получение ленты уловов с фильтрацией

## Аутентификация

API использует JWT Bearer токены для аутентификации:

```
Authorization: Bearer <token>
```

### Получение токена
1. Зарегистрируйтесь через `POST /auth/register`
2. Войдите в систему через `POST /auth/login`
3. Используйте полученный токен в заголовке `Authorization`

## Конфигурация

### Основные настройки
- **Пакет**: `darkaonline/l5-swagger`
- **Версия OpenAPI**: 3.0.0
- **Автогенерация**: Включена в режиме разработки
- **Формат**: JSON

### Файлы конфигурации
- `config/l5-swagger.php` - Основная конфигурация
- `app/Http/Controllers/SwaggerController.php` - Базовые аннотации
- `storage/api-docs/api-docs.json` - Сгенерированная документация

## Добавление новых эндпоинтов

Для документирования новых эндпоинтов добавьте аннотации в контроллеры:

```php
/**
 * @OA\Post(
 *     path="/your-endpoint",
 *     tags={"YourTag"},
 *     summary="Краткое описание",
 *     description="Подробное описание",
 *     @OA\RequestBody(
 *         required=true,
 *         @OA\JsonContent(
 *             @OA\Property(property="field", type="string", example="value")
 *         )
 *     ),
 *     @OA\Response(
 *         response=200,
 *         description="Успешный ответ",
 *         @OA\JsonContent(
 *             @OA\Property(property="success", type="boolean", example=true)
 *         )
 *     )
 * )
 */
public function yourMethod(Request $request)
{
    // Ваш код
}
```

## Регенерация документации

После добавления новых аннотаций:

```bash
php artisan l5-swagger:generate
```

## Тестирование

Используйте встроенный тестовый скрипт:

```bash
php test-swagger.php
```

## Преимущества для сторонних разработчиков

1. **Автоматическая документация** - Все изменения в API автоматически отражаются в документации
2. **Интерактивное тестирование** - Можно тестировать API прямо в браузере
3. **Генерация SDK** - Автоматическая генерация клиентских библиотек
4. **Валидация** - Проверка корректности запросов и ответов
5. **Примеры** - Готовые примеры использования для каждого эндпоинта
